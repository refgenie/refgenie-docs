# refgenie-docs (deprecated)

This repository is no longer used. Its build and deploy workflow is disabled.

The refgenie docs now live next to the code they describe, and
[docs.refgenie.org](https://docs.refgenie.org) is built from them:

- Refgenie: the [`docs/`](https://github.com/refgenie/refgenie/tree/alpha/docs) folder of
  [refgenie/refgenie](https://github.com/refgenie/refgenie)
  (`docs/refgenie/` for the guides, `docs/site/` for the home page, legacy docs and SKILL.md)
- Refget: the [`docs/`](https://github.com/refgenie/refget/tree/master/docs) folder of
  [refgenie/refget](https://github.com/refgenie/refget)

Edit the docs there, not here.
